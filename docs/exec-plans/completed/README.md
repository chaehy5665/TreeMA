# Completed Execution Plans

## Purpose

Define how completed execution plans are archived after work ships or otherwise finishes.

## Canonical For

- Archival location and retention rules for completed plans

## Not Canonical For

- The implementation details of any specific finished change

Store shipped or otherwise finished execution plans in this directory.

- Move plans here after implementation is complete.
- Keep the original implementation context and validation notes intact.
- Do not leave stale copies in `../active/`.
